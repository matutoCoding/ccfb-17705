# 隐形矫治排牙分步审核系统

浏览器端的隐形矫治方案审核工具：TypeScript + WebGL2，重计算放 Web Worker，病例存 IndexedDB。零运行时第三方依赖。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 类型检查 + 生产构建（输出 dist/）
npm test         # 引擎确定性/限值/碰撞/分割测试（Node + tsx）
```

## 六个页面

1. **病例列表** — 新建/删除/打开病例，可一键生成程序化拥挤上下颌或理想排列对照
2. **模型导入** — 上传二进制/ASCII STL，Worker 内曲率+分水岭自动分割 14 颗牙，支持笔刷手动改涂，确认入病例并补建统计牙根
3. **目标排牙** — 点选拖牙、按局部坐标系精确平移/转矩微调、沿牙弓弧长自动排齐，平移量与旋转角分开显示
4. **分步方案** — 自动切步、Worker 逐步碰撞、IPR 邻面去釉、附件放置、牙套偏移壳体、步骤滑杆/自动播放
5. **咬合检查** — 正中/前伸/左右侧方四工况，接触点按咬合松紧着色分级
6. **审核报告** — 每牙总移动、风险步骤、去釉清单、碰撞明细，浏览器打印/另存 PDF

## 核心设计

### 确定性切步（`src/core/planning.ts`）
- 纯函数，无 DOM/时间依赖；每颗牙按总位移求步数 `n_i=ceil(总量/限值)`，整体步数 `N=max(n_i)`，所有牙同步分 N 段
- 平移线性插值、旋转四元数 slerp，固定 `k/N` 形式；集合按 FDI 升序迭代
- 同输入两次结果**位级一致**，输入参数指纹（FNV-1a）随方案保存
- 物理限值绝不被突破：实测单牙单步平移 ≤0.25mm、旋转 ≤2°；超过 `maxSteps` 只打标记不放大单步量

### 碰撞引擎（`src/core/collision.ts`）
- 顶点-三角面最近距离 + 面法线有符号判定（点在面内侧取负=穿透），避免顶点法线在凸面的假阳性
- 空间哈希粗筛 + 三角面包围球剔除；局部面法线/包围球用 WeakMap 缓存，不随步重建
- 遍历顺序固定（FDI 排序、哈希桶按索引），结果确定性
- 同颌仅检查邻接牙对（弓序号差 ≤2，中线只允许中切牙对）

### 渲染（`src/renderer.ts`）
- WebGL2 实例化绘制：静态 VBO 存几何，每实例一个模型矩阵+颜色；拖步骤只更新实例缓冲
- 脏标记：无变化的网格零 GL 上传，headless 实测拖动 ~52fps

### 数据
- IndexedDB 结构化克隆原生存 TypedArray，`Segmentation.seeds` 的 Map 手动转数组
- STL 二进制/ASCII 解析（坐标量化合并重复顶点）与导出

## 测试模型

`src/core/caseGenerator.ts` 用 mulberry32 确定性 PRNG 生成：参数化超二次曲面牙冠（含牙尖/切缘/颈缘特征）、统计模型分叉牙根、U 形牙龈。拥挤病例弓长压缩 72% 并加扭转/唇向错位；同种子位级一致。
